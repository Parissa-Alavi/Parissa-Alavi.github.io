# Parissa Alavi Portfolio Site

This repository contains a lightweight GitHub Pages portfolio built as a static website.

## Files
- `index.html` — homepage and portfolio landing page
- `styles.css` — styling and responsive layout
- `script.js` — small interactive scripts for navigation
- `cv.html` — CV view page

## Preview locally
Open `index.html` directly in a browser, or serve the folder with a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish on GitHub Pages
Because the repo name is `parissa_alavi.github.io`, the site will be published automatically at:

https://parissa_alavi.github.io/

## Customization
Update the text, publication links, and contact details in `index.html`, and replace the placeholder CV details in `cv.html` with your actual information.
